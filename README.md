##  Tech Stack

**Backend**
- Node.js, Express, MongoDB (Mongoose)
- JWT authentication
- Bcrypt password hashing
- CORS for API security

**Frontend**
- React (Vite)
- React Router
- Tailwind CSS

**Tooling**
- ESLint
- PostCSS

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/adarshtiwari908/Aether.git
cd Aether

2. Install dependencies


Backend:
cd backend
npm install


Frontend:
cd frontend
npm install


3. Configure environment variables
Create a .env file
PORT=5000
MONGODB_URI=?your mongo_uri
JWT_SECRET_KEY=your-very-secure-secret
